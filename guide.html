    Setup guide

    Live on your stream in 2 minutes

    Two browser sources in OBS. No downloads, no accounts.

    1

    Add it to OBS

    Two pieces from the same page — the wheel goes on your stream, the controls stay private in a dock.

    On stream https://abdulazizjhk.github.io/giveaway-wheel/wheel.html?view=stage
    Your controls https://abdulazizjhk.github.io/giveaway-wheel/wheel.html?view=dock
    1. In your scene, Sources → ➕ Browser → paste the On stream URL → set 1920 × 1080 → uncheck “Shutdown source when not visible”. It’s transparent, so it sits over your scene.
    2. Top menu Docks → Custom Browser Docks… → name it “Giveaway” → paste the Your controls URL → Apply. Dock it wherever you like — only you see this.
    💡
    Seeing an old version after an update? Grab a fresh On stream URL with the 🔗 Copy source URL button in your dock’s ⚙️ Settings tab — it stamps the current version (e.g. &v=1.5) so pasting it forces a clean load. You can also right-click the source → Refresh, or bump the &v= number yourself.
    2

    Run a giveaway

    1. In the dock’s 🎡 Giveaway tab, type your Twitch channel → Connect (no login needed — it reads chat anonymously).
    2. Set a Timer (e.g. 60s) and click ▶ Open Entries in the bar at the bottom of the dock. Viewers type !join to enter — the on-stream banner shows the live count + countdown.
    3. When the timer ends it auto-spins. Or press Spin / Space any time.
    4. The winner is revealed with confetti — and if you added rewards, the prize (and its image) shows too.
    3

    Add rewards & prizes

    • Add prizes in the dock’s 🎁 Rewards tab. In Entrants mode the winner automatically gets the top reward; in Rewards mode the roulette picks the prize and gives it to a random entrant.
    • Click the 🖼️ next to a reward to attach an image (logo / prize art) — it reveals big when that prize is won.
    4

    Chat announcements OPTIONAL

    Want the bot to post “🏆 @winner won {reward}!” to chat? In the dock’s 💬 Chat bot tab:

    1. Get an OAuth token at twitchtokengenerator.com (scopes: chat:edit, chat:read).
    2. Enter your channel/bot username + the token → Connect bot → tick Post event messages. The token stays only in your browser.
